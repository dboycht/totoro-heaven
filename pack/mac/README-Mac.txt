龙猫天堂（totoro-heaven）macOS 版 1.3.9-pre1
================================================

【启动】
1. 本机需装有 Node.js 20 或更高版本（终端里输 `node -v` 可查）。
2. 双击 pack/mac/totoro-heaven-mac.command —— 会打开一个终端窗口并自动启动本地服务，
   服务只监听本机（127.0.0.1），随后自动打开浏览器。
3. 停止：在那个终端窗口按 Ctrl+C（或直接关闭该窗口）。

【说明】
· 单实例：程序已在运行时再次启动，会自动把浏览器指向已运行的实例并退出。
· 端口 3000~3020 被其它程序占用时会自动顺延到下一个可用端口；也可用环境变量 TOTORO_PORT 指定。
· macOS 上「一键获取 token」不可用（扫描器只支持 Windows 微信客户端），按钮为灰色：
  按首次教程用抓包工具取得 token 后，粘贴到工作台的 token 输入框即可。
· 首次打开若系统提示来自未知开发者：右键 .command 文件 →「打开」即可（本包未经公证签名）。
· 数据（本机记录 / 预设 / token）都只存在你自己的电脑里；删除本目录即整体移除。

【隐私】
token 只存在本机浏览器的 localStorage；不打印、不入库。请遵守你所在学校的规定，风险自负。
