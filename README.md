# 龙猫天堂

一款以「天堂」为主题的迷你像素跑酷小游戏。

> 踩着云朵、越过树桩、收集橡果 —— 打开就是一片霞光里的浮岛与云海。

## 玩法

小猫会一直向右跑，你要帮它跳过路上的树桩、顺手把橡果吃掉。

| 按键 | 作用 |
| --- | --- |
| `↑` / `A` | 跳（按住可以跳得更高） |
| `↓` / `B` | 蹲下（能钻过矮处的横杆） |
| `→` / `B` | 加速 |
| `←` | 减速 |
| `Enter` | 撞到后重来 |

- 打开后先是**静止的开场画面**，按任意键开始跑；
- 撞到树桩就结束，画面会显示本次吃到的橡果数；
- 最高分只记在本次打开期间（关掉就重置）。

## 关于这个仓库

这是一个**小游戏项目**：画面全部用 Canvas 现画，不依赖任何图片、字体或游戏引擎 ——
所以它非常小，也能完全离线运行。

- 技术栈：Nuxt 3 + Vue 3（纯前端，无后端、无账号、无联网）
- 运行方式：打开即玩，不需要注册或登录
