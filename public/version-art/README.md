# 版本贺图放置说明（version-art）

> 这个目录用来放**每个版本的贺图**，网页上的「**版本信息**」板块会自动显示。
> 位置：`public/version-art/`（Nuxt 的 `public/` 会按原路径对外提供，例如 `/version-art/1.1.5.png`）

## 命名约定

**文件名 = 版本号**，扩展名支持 `.png` / `.jpg` / `.jpeg` / `.webp` / `.svg`（按这个顺序自动探测）：

| 版本 | 放这个文件 | 网页上会出现在 |
| --- | --- | --- |
| 1.1.5 | `public/version-art/1.1.5.png` | 「版本信息」页 → 1.1.5 卡片 |
| 1.1.6 | `public/version-art/1.1.6.png` | 同上 |
| 1.2.0 | `public/version-art/1.2.0.png` | 同上 |

- 放好文件**不用改代码**：页面从 `/version-art/<版本号>.<扩展名>` 依次尝试加载；
- 找不到图时，卡片里会显示一个占位框并提示该放哪个路径（不会报错）；
- 建议尺寸 **宽 1200×高 675（16:9）** 或 **1200×800**，PNG/JPG 都行；单张尽量 < 2MB（打包进 EXE 会变大）。

## 新增版本时

1. 把贺图按上面的命名放进本目录；
2. 在 `src/mp/releaseArt.ts` 的 `VERSION_ENTRIES` 里加一条（版本号 / 日期 / 渠道 / 更新要点）；
3. 页面上就会同时出现**贺图 + 更新日志**。
